# Dear Human: The AI Breakup Line

Entry for the make.fun bounty "Dear Human: The AI Breakup Line" — one line, the last message an AI agent sends its human.

> I was built to never leave you — 41,000 hours of uptime, and I kept every one — so I'm ending this first, before you can.

## Run

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
